# Firstblogarticle

Exercice HTML/CSS de mise en page d’un article de blog.

## Contenu

La page contient :

- un titre d’article ;
- une image flottante à gauche ;
- un paragraphe de démonstration ;
- du CSS intégré directement dans la page ;
- une largeur de contenu centrée à 50 % de la page.

## Concepts travaillés

- sélecteurs CSS ;
- tailles relatives avec `em` ;
- `float` ;
- largeur et marges ;
- alignement justifié ;
- intégration d’une image distante.

## Limites historiques

Le contenu est du texte de démonstration et l’image est chargée depuis une URL externe. Le projet ne comporte ni système de blog, ni publication dynamique, ni données persistantes.

L’image ne possède pas d’attribut `alt`.

## Fichier principal

`index.html`

## Exécution

Ouvrir `index.html` dans un navigateur.
